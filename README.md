# SportNest

## Purpose
SportNest is a sports facilities booking platform where users can explore, book, manage, and delete sports facilities easily through a modern and responsive web application.

---

## Live URL
🔗 https://sportnest-neon.vercel.app/

---

## Features
- User Authentication & Authorization
- Book Sports Facilities
- Add New Facilities
- Update Facility Information
- Delete Facilities
- Responsive Design for Mobile & Desktop
- Dynamic Booking Management
- Secure Private Routes
- Real-time Toast Notifications

## Installation & Setup

### Clone the repository
```bash
git clone https://github.com/your-username/sportnest.git
```

### Install dependencies
```bash
npm install
```

### Run the project
```bash
npm run dev
```

---

## Environment Variables
Create a `.env.local` file and add the required environment variables.

Example:
```env
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret
NEXT_PUBLIC_API_URL=your_api_url
```
